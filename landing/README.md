# Лендинг и промо-ролик English Buddy

Статичный сайт без фреймворков и сборки: один `index.html` + картинки в `assets/`.
Цвета, шрифты и мотивы — по `docs/brand.md`.

```
landing/
├── index.html                 лендинг (HTML + CSS + JS в одном файле)
├── assets/
│   ├── favicon.svg            иконка (светлая/тёмная тема внутри SVG)
│   ├── logo.svg               логотип с надписью (текст в кривых, шрифт не нужен)
│   ├── og.png                 превью для Telegram и соцсетей, 1200×630
│   └── apple-touch-icon.png   иконка для iOS, 180×180
└── promo/
    ├── promo.html             ролик как HTML-анимация (кадр = функция времени)
    ├── capture.js             рендер кадров через Playwright → MP4 через ffmpeg
    ├── og.html, render-og.js  шаблон и рендер og.png / apple-touch-icon.png
    └── out/
        ├── promo_9x16.mp4     1080×1920, 30 fps, H.264, без звука, 27 с
        ├── promo_1x1.mp4      1080×1080, то же
        └── promo_poster_9x16.png, promo_poster_1x1.png   обложки (кадр-хук)
```

Чтобы посмотреть сайт, откройте `index.html` в браузере. Для публикации подойдёт любой статический хостинг: залейте папку `landing/` целиком, кроме `promo/`.

## Что поменять перед запуском

Все настройки лежат в начале `<script>` внизу `index.html`, в блоке «НАСТРОЙКИ — правьте здесь».

**Ссылка на бота**: `const BOT_URL = "https://t.me/YOUR_BOT";`. Все кнопки берут ссылку отсюда и сами добавляют `?start=landing`.

**Метки для рекламы.** Если открыть лендинг как `https://сайт/?start=ad_video` или `?utm_campaign=ad_video`, во все кнопки подставится `?start=ad_video`. Для каждой кампании ничего править не надо. Telegram пропускает в метке только латиницу, цифры, `_` и `-`, не длиннее 64 символов; лишнее скрипт заменит сам. Чтобы задать отдельную метку одной кнопке, добавьте ей атрибут `data-start="…"`, а тарифу — поле `start: "…"` в `PLANS`.

**Цены**: массив `PLANS`. Карточки строятся из него в том же порядке:

```js
{
  name: "Premium", price: "490 ₽", period: "в месяц",
  alt: "или 2 990 ₽ в год",           // необязательно
  badge: "Для тех, кто всерьёз",      // необязательно, жёлтая наклейка
  note: "Больше голоса и уроков",     // подзаголовок
  features: ["Безлимитный голос", "3 урока в день"],
  cta: "Попробовать Premium",
  highlight: true,                    // выделить рамкой и жёлтой кнопкой
}
```

Строка под тарифами задаётся в `PRICING_NOTE`; сейчас там «или оплата звёздами Telegram». Если оставить её пустой, строка пропадёт.

Сверьте цены с ботом: в `app/config.py` уже заданы `stars_month = 350`, `stars_quarter = 900` и `stars_year = 2400` ⭐, а за флагом есть пробная неделя Premium (`TRIAL_WELCOME` в `app/bot/texts.py`). Если пробную неделю включите, о ней стоит сказать в карточке, например `note: "Первая неделя — бесплатно"`. Цены в звёздах можно дописать в `alt` или `PRICING_NOTE`.

**Отзывы**: массив `REVIEWS = [{ text: "…", author: "Имя, город" }]`. Пока он пуст, на сайте честная заглушка «Здесь будут отзывы первых пользователей». Вписывайте только настоящие отзывы и только с разрешения авторов.

**Превью ссылки (Open Graph).** В `<head>` замените `YOUR_DOMAIN` на адрес сайта: так написано в `og:url`, `og:image` и `twitter:image`. Ссылки должны быть абсолютными, иначе Telegram не покажет картинку. Если поменяли `promo/og.html`, перерисуйте картинки командой `cd promo && node render-og.js`.

**Проверьте тексты, за которые отвечает продукт:**
- FAQ «Как оплатить из России?» обещает оплату звёздами Telegram. Проверьте, что звёзды можно купить с российской карты и что оплата в боте работает.
- FAQ «Что с моими сообщениями и голосом?» должен совпадать с политикой конфиденциальности. Ссылки на политику пока нет, её стоит добавить в подвал.
- Карточки с меткой «новое» (подкаст, прокачка слов, темы для тебя, «скажи как носитель», друг пишет первым, фото → карточки) описывают фичи, которые сейчас в разработке. Если какая-то не выйдет к запуску, уберите карточку или метку.
- Цифры в макетах (серия 12 дней, «ошибок на 10 сообщений 2,3», «very good 7 раз») — это пример экрана, он так и подписан. Это не статистика.

## Промо-ролик

Сюжет: «Боишься говорить по-английски?» — красная ручка зачёркивает «Боишься», и микрофон «падает» в чат. Дальше голосовое с ошибкой *I am agree*, ответ Jake голосом, правка ручкой и маркером. Чип «I agree» перелетает в урок «Тема: компьютеры / Разбор ошибок». Потом две быстрые фичи — «Подкаст про тебя» и «Прокачка слов», — и финальная плашка с логотипом, «Попробуй бесплатно в Telegram» и `t.me/…`. Звука нет: ролик рассчитан на просмотр без звука, всё держат крупные титры. Раскадровка с вариантами каждой сцены лежит комментарием в начале `promo/promo.html`.

### Перерендерить

Нужны Node.js, Playwright с Chromium (`require('playwright')`) и ffmpeg.

```bash
cd landing/promo
node capture.js --bot my_buddy_bot            # оба формата, юзернейм в финальной плашке
node capture.js --format vertical             # только 9:16 (square — только 1:1)
node capture.js --stills 2.9,11.3,25          # только PNG-кадры для проверки → out/stills
node capture.js --samples 1                   # быстрый черновик без размытия движения
```

Полный рендер одного формата занимает около 3 минут на 4 ядрах. Каждый кадр собирается из пяти подкадров (плюс размытие по скорости на быстрых пролётах), чтобы получилось естественное размытие движения. Файлы весят около 5–6 МБ (лимит площадок не жмёт).

**Посмотреть в браузере:** откройте `promo/promo.html`. Пробел ставит на паузу, стрелки перематывают. Параметры: `?format=square` — квадратная версия, `&t=11.3` — заморозить кадр на секунде 11.3, `&bot=имя` — юзернейм в плашке.

**Править:** тексты титров заданы в `makeCap(...)`, тайминги — в объекте `T`, раскладка для двух форматов — в объекте `L`. Каждый кадр полностью вычисляется из времени, поэтому любую секунду можно перерендерить отдельно.

В рекламе лучше вести на бота с меткой (`t.me/имя_бота?start=ad_video`) или на лендинг с `?start=ad_video`.

## Три хука на 15 секунд для следующих тестов

Каждому варианту — своя метка `start`, тогда в боте видно, какой креатив приводит людей, которые потом остаются.

**1. «Понимаешь, но молчишь»** (`?start=ad_silent`). Угол — разрыв между «понимаю» и «говорю», знакомый почти каждому взрослому.
- 0–2 с. Титр «Понимаешь английский, но молчишь?». Курсор мигает в пустом поле ввода, набранная фраза стирается.
- 2–6 с. Палец зажимает микрофон, идёт таймер голосового. Расшифровка: *I want to tell about my job…*
- 6–10 с. Jake отвечает голосом, волна играет, титр «Друг ответит. Без оценок». Ниже маркером: *tell ~~about~~ → talk about*.
- 10–15 с. Титр «5 минут в день — и ты говоришь», CTA `t.me/…`.

**2. «Тебе прислали подкаст. Про тебя»** (`?start=ad_podcast`). Угол — любопытство и персонализация.
- 0–2 с. Уведомление в Telegram: «Новый выпуск: твоя неделя». Титр «Про тебя записали подкаст».
- 2–9 с. Плеер, Jake и Emma с субтитрами: *“He said ‘I am agree’ on Monday… and by Friday — ‘I agree’!”* На слове *agree* — штрих маркера.
- 9–12 с. Титр «Каждую неделю — 2 минуты про твой английский».
- 12–15 с. «Болтай с другом в Telegram — подкаст соберётся сам», CTA.

**3. «very good ×7»** (`?start=ad_words`). Угол — словарный застой у среднего уровня.
- 0–2 с. Огромное *very good* и счётчик ×7, красная ручка его зачёркивает. Титр «Ты говоришь “very good” 7 раз в день».
- 2–8 с. Карточки «Прокачки слов» на твоей же фразе: *The film was ~~very good~~ → gripping / brilliant / a must-see*.
- 8–12 с. Кнопка «Скажи как носитель»: *I want to ask you about one question* → *Can I ask you something?*
- 12–15 с. Титр «Звучи как носитель», CTA.

Что сравнивать: CTR и цену клика по креативу, долю /start по метке и долю тех, кто на второй день прислал хотя бы одно голосовое. Последняя метрика важнее клика.
